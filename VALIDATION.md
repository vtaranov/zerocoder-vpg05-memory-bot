# Проверка VPg05

Дата: 4 ноября 2026 года. Python 3.13.15; openai 2.54.0; pinecone 8.1.2; pyTelegramBotAPI 4.37.1; python-dotenv 1.2.4.

Автономные тесты: 12/12. `pip check`: конфликтов зависимостей нет.

## Реальные OpenAI и Pinecone

Модель: `gpt-6-luna`. Эмбеддинги: `text-embedding-3-small`, 1536 измерений. Порог кандидата: 0.75. После отбора модель различает перефразирование, исправление и новую информацию.

| Сообщение | Результат | Cosine |
|---|---|---|
| Я хочу полететь на Марс. | `inserted` | нет записей |
| Я хотел бы полететь на Марс. | `skipped` | 0.953613 |
| Я хочу полететь на Марс. | `skipped` | 1.000000 |
| Я не хочу полететь на Марс. | `updated` | 0.864879 |
| Мой брат хочет полететь на Марс. | `inserted` | 0.701272 |
| Я люблю пиццу. | `inserted` | 0.210111 |

Дополнительно проверены: отсутствие необязательных полей профиля, исключение `bot_response`, изоляция владельцев, восстановление памяти после нового подключения, генерация ответа по сохранённым сведениям, очистка только своего пространства. Успешный запуск удалил свои тестовые записи, сохранив остальные пространства.

Фактический ответ после повторного подключения: «Судя по вашим прежним словам, вы не хотите полететь на Марс. Вопрос сам по себе этого не меняет.».

В первом запуске выявлена ошибка вызова отсутствующего `Pinecone.close()` в SDK 8.1.2. Вызов удалён, весь сценарий повторён успешно. Неуспешный и успешный протоколы сохранены локально; тестовые пространства первого запуска очищены отдельно.

Это проверка небольшой учебной выборки, а не оценка точности дедупликации на произвольных диалогах. Ответы и решения модели не являются независимой экспертной проверкой.
